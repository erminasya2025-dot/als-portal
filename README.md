ALS — Algology Learning System
================================
Ovo je početni, responzivni HTML/CSS/JavaScript prototip ALS portala.

Fajlovi:
- index.html — struktura stranice i početni sadržaj
- style.css — izgled i prilagodba za mobitele
- script.js — pretraga sadržaja i dinamička godina u podnožju

Lokalni pregled:
Otvorite index.html u web-pregledniku.

Besplatno objavljivanje preko GitHub Pages:
1. Napravite GitHub račun na https://github.com
2. Kreirajte novi PUBLIC repository, npr. als-portal.
3. Učitajte index.html, style.css, script.js i README.md u glavni direktorij.
4. Otvorite Settings → Pages.
5. U odjeljku Build and deployment odaberite Deploy from a branch.
6. Odaberite branch main i folder /(root), pa Save.
7. Nakon objave stranica će biti dostupna na adresi oblika https://KORISNICKO-IME.github.io/als-portal/

Napomena:
- Ovo je front-end prototip, nije sistem s korisničkim računima ni bazom podataka.
- Uklonite ili zamijenite kontakt adresu als.portal@example.com prije objave.
- Dodajte vlastite provjerene tekstove, izvore, fotografije i pravne informacije prije javnog predstavljanja.
- Google Fonts se učitava s interneta; ostatak stranice je statičan.
